# build instructions

- Install rhombus from nightly snapshot:
https://users.cs.utah.edu/plt/rhombus-snapshots/
- I used October 2nd 2026
- Add rhombus to PATH in rhombus/bin
- Clone my glide library https://github.com/oflatt/rhombus-glide
and install it with raco pkg install ./glide-pptx. 
- run `rhombus talk.rhm`
